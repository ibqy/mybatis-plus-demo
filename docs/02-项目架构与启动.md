## 1. 技术栈分别负责什么

- Spring Boot：启动应用、创建和管理对象、读取配置、提供 Web 服务。
- MyBatis：执行 SQL、绑定参数、把结果映射为 Java 对象。
- MyBatis-Plus：在 MyBatis 上提供通用 CRUD、条件构造器、分页和代码生成等能力。
- JDBC Driver：按 JDBC 标准与 MySQL 通信。
- Maven：解析依赖、编译、测试、打包。

依赖声明可查看 [pom.xml](../pom.xml#L30)。项目使用 Spring Boot 4 对应的 `mybatis-plus-spring-boot4-starter`，不要同时再引入普通 MyBatis Starter，以免自动配置冲突。

## 2. 一次请求经过哪些层

以 `GET /api/demo1/users` 为例：

```text
浏览器/curl
  → Spring MVC 找到 UserLessonController.list()
  → userService.list()
  → UserMapper 动态代理
  → BaseMapper 中预先注册的 selectList SQL
  → MyBatis 参数处理和插件链
  → JDBC Driver
  → MySQL
  → ResultSet 映射成 List<User>
  → Jackson 序列化为 JSON
```

跳转查看：

- [Controller 的 list 方法](../src/main/java/com/xb/mybatisplus/controller/UserLessonController.java#L58)
- [UserService 继承 IService](../src/main/java/com/xb/mybatisplus/service/UserService.java#L17)
- [UserMapper 继承 BaseMapper](../src/main/java/com/xb/mybatisplus/mapper/UserMapper.java#L19)

## 3. 启动项目

### 3.1 检查 Java 和 Maven Wrapper

```powershell
$env:JAVA_HOME='C:\Users\xb1\.jdks\ms-21.0.11'
.\mvnw.cmd -v
```

输出应显示 Java 21 和 Maven 3.9.16。

### 3.2 无公司内网：使用 local 模式

```powershell
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=local"
```

它使用 H2 内存数据库，配置见 [application-local.yml](../src/main/resources/application-local.yml#L5)。停止应用后数据消失，适合练习。

### 3.3 有公司内网：使用 MySQL

```powershell
.\mvnw.cmd spring-boot:run
```

默认连接配置见 [application.yml](../src/main/resources/application.yml#L10)。实际项目应通过 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD` 环境变量提供凭据，不应把生产密码提交到版本库。

### 3.4 发出第一个请求

```powershell
curl.exe http://localhost:8080/api/demo1/users
```

同时观察应用控制台中的 `Preparing`（SQL）与 `Parameters`（参数）。这是学习 ORM 最有效的方法之一：始终确认框架最终发出了什么 SQL。

## 4. Spring Boot 自动配置做了什么

启动类上的 `@SpringBootApplication` 组合了配置、自动配置和组件扫描。查看[启动类](../src/main/java/com/xb/mybatisplus/MybatisPlusDemoApplication.java#L23)。

启动时大致发生：

1. 读取 `application.yml` 并创建 `DataSource`。
2. MyBatis-Plus Starter 创建 `SqlSessionFactory` 和 `SqlSessionTemplate`。
3. `@MapperScan` 找到 Mapper 接口，为它们注册代理 Bean。
4. 组件扫描找到 Controller、Service、Config、异常处理器。
5. 执行初始化 SQL，随后启动内嵌 Web Server。

Spring 的依赖注入让 Controller 只声明构造参数，不需要自己 `new UserServiceImpl()`。查看[构造器注入](../src/main/java/com/xb/mybatisplus/controller/UserLessonController.java#L51)。

## 5. 分层不是为了多建文件

| 层 | 本项目类 | 核心职责 | 不应承担 |
|---|---|---|---|
| Controller | `UserLessonController` | HTTP 参数、状态码、响应 | 拼复杂 SQL、开启业务事务 |
| DTO | `CreateUserRequest` | 外部输入结构和校验 | 数据库持久化行为 |
| Service | `UserServiceImpl` | 业务规则、事务、编排 | 理解 HTTP 细节 |
| Mapper | `UserMapper` | 数据访问 | 业务流程 |
| Entity | `User` | 数据库行映射 | 接收任意外部字段 |

小项目可以精简层次，但每种职责依然要能说清楚。

## 6. 配置优先级入门

`${DB_USERNAME:xdb}` 表示：优先使用环境变量 `DB_USERNAME`，没有才使用默认值 `xdb`。Profile 配置会覆盖基础配置，所以 `local` 能把 MySQL DataSource 换成 H2。

## 7. 动手实验

1. 把 `server.port` 临时改成 9090，验证请求地址也要变化。
2. 注释掉 `@MapperScan`，观察启动或调用时的错误，再恢复。
3. 找到启动日志中的连接池、Mapper 和 Tomcat 初始化信息。
