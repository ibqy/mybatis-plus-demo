## 1. 代码生成器的定位

生成器根据数据库元数据创建 Entity、Mapper、Service、Controller 和 XML 骨架。它减少机械劳动，但不能生成正确业务逻辑，也不能替代代码审查。

查看完整配置：[MybatisPlusCodeGenerator](../src/main/java/com/xb/mybatisplus/generator/MybatisPlusCodeGenerator.java#L20)。

主要配置分组：

- DataSource：从哪个数据库读取表结构。
- GlobalConfig：作者、输出目录等。
- PackageConfig：生成到哪些包。
- StrategyConfig：包含哪些表、去掉什么前缀、覆盖策略。
- TemplateEngine：如何渲染模板，本项目用 Freemarker。

## 2. 运行生成器

先确保 MySQL 中已有 `demo_user`，再执行：

```powershell
.\mvnw.cmd exec:java "-Dexec.mainClass=generator.com.xb.mybatisplus.MybatisPlusCodeGenerator"
```

结果位于 `target/generated-code`，不会覆盖手写教学源码。先检查生成结果，再按项目规范复制和修改。不要把生成目录直接当作完成的业务模块。

可用 JVM 参数临时覆盖数据源：

```powershell
.\mvnw.cmd exec:java `
  "-Dexec.mainClass=generator.com.xb.mybatisplus.MybatisPlusCodeGenerator" `
  "-Ddb.url=jdbc:mysql://localhost:3306/mybatis_plus_demo" `
  "-Ddb.username=root" `
  "-Ddb.password=你的密码"
```

## 3. 集成测试为什么使用 H2

[UserMapperIntegrationTest](../src/test/java/com/xb/mybatisplus/UserMapperIntegrationTest.java#L35) 验证 Mapper、XML、逻辑删除和分页，但使用内存 H2，避免测试误改共享 MySQL。

```powershell
.\mvnw.cmd clean test
```

当前测试验证：

- 普通查询自动过滤逻辑删除记录；
- `deleteById` 实际更新 deleted；
- XML 参数与结果映射正确；
- 分页记录数与 total 正确；
- 新增时自增主键、业务默认值和时间字段自动填充；
- 乐观锁正常更新 version，并拒绝旧 version 覆盖；
- required 查询把不存在记录转换成明确的资源不存在异常。

H2 的 MySQL 兼容模式并不等同真正 MySQL。使用数据库特有函数、索引和执行计划时，还需要隔离的 MySQL 集成环境。

## 4. 推荐调试顺序

出现数据库问题时，从外向内检查：

1. HTTP 状态码和响应体是什么？
2. Controller 是否收到预期参数？
3. 控制台 `Preparing` SQL 是否正确？
4. `Parameters` 的值和类型是否正确？
5. 把等价 SQL 放进数据库客户端能否执行？
6. 表结构、字段、数据和账号权限是否符合预期？
7. 异常最底层的 `Caused by` 是什么？

不要只看最上面一句“Bean 创建失败”；根因通常在异常链底部。

## 5. 常见错误速查


| 现象                        | 常见原因                     | 检查点                        |
| --------------------------- | ---------------------------- | ----------------------------- |
| Mapper 无法注入             | 未扫描、包路径错误           | `@MapperScan`                 |
| Table doesn't exist         | 库名/表名/Profile 错误       | JDBC URL、`@TableName`        |
| Unknown column              | 实体与表不一致               | 字段、`@TableField`、迁移脚本 |
| Invalid bound statement     | XML 未加载或 namespace/id 错 | mapper-locations、接口方法    |
| 参数 not found              | 缺少或写错`@Param`           | Mapper 与 XML 参数名          |
| 分页没效果                  | 未配置分页插件/解析器        | `MybatisPlusConfig`、pom      |
| 乐观锁一直失败              | version 不是最新值           | 先查询再更新                  |
| 被删除数据仍出现            | 手写 SQL 忘记过滤            | `deleted=0`                   |
| Communications link failure | 地址、端口、VPN、网络        | DNS、端口、内网路由           |

## 6. 最终构建检查

```powershell
.\mvnw.cmd clean test
.\mvnw.cmd -DskipTests package
java -jar target/mybatis-plus-demo-1.0.0.jar --spring.profiles.active=local
```

构建成功只能证明编译和自动测试通过；还应调用关键接口做冒烟测试。
